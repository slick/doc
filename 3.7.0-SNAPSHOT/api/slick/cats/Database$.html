  16.  def resource(config: DatabaseConfig): Resource[IO, Database]

    Open a new database as a Resource and always close it.

    Open a new database as a Resource and always close it.

    Each invocation opens a new database instance, so this should usually wrap the whole program that needs a database, not individual queries.

    Acquire this once at the top-most level and pass it down. In normal application usage, keep only one opened database at a time.
